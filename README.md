# Task Flow

Task Flow is a simple task management website made using HTML, CSS, and JavaScript.

## Features
- Add new tasks
- Delete tasks
- Drag and drop tasks between sections
- Three task sections:
  - To Do
  - In Progress
  - Completed
- Simple and responsive design

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
